# موقع السيرة الذاتية والمنشورات العلمية (Bio & Publications Site)

موقع شخصي حديث، مرن، ومتجاوب بالكامل مع الهواتف الذكية لمشاركة منشوراتك العلمية وأوراقك البحثية في مجلد `pubs/` مع زوار موقعك مباشرة. يتميز الموقع بتصميم معدني فضي/رمادي فاخر يعتمد على نظام البطاقات الزجاجية (Glassmorphic Cards) مع تأثيرات حركية انسيابية مأخوذة من واجهة مشروع Odysseus.

## 🚀 كيفية الإعداد والتشغيل لأول مرة (Initial Setup)

لتشغيل الموقع وربطه بصفحة جيت هاب (GitHub Pages) الخاصة بك، اتبع الخطوات التالية:

### 1️⃣ تهيئة مستودع Git وربطه بجيت هاب
افتح محطة الأوامر (Terminal) أو PowerShell في هذا المجلد ونفّذ الأوامر التالية:

```bash
# تهيئة مشروع Git محلي
git init

# إضافة الملفات
git add .
git commit -m "Initial commit: Setup Bio Site"

# ربط المشروع بمستودع جيت هاب الخاص بك (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

# تغيير اسم الفرع الرئيسي لـ main ورفع الملفات
git branch -M main
git push -u origin main
```

### 2️⃣ إعداد شعارك الخاص (Logo)
قم بحفظ صورتك أو شعارك باسم **`logo.png`** في المجلد الرئيسي للمشروع مباشرة.
> 💡 **ملاحظة:** في حال عدم توفر الصورة، سيقوم الموقع تلقائياً بعرض شعار احترافي بديل (شعار كأس هجيا وأفعى أسكليبيوس الطبية) كشعار افتراضي.

## 🤖 كيف يعمل البوت لرفع الأبحاث تلقائياً؟ (Automated Workflows)

لقد وفرنا لك طريقتين لأتمتة تحديث الموقع عند إضافة، حذف، أو تعديل ملفات PDF داخل مجلد `pubs`:

### 🅰️ الطريقة الأولى: البوت المحلي (Local Watcher Bot) - *موصى بها*
عندما تعمل على جهاز الكمبيوتر الخاص بك، يمكنك تشغيل بوت المراقبة المحلي الذي يكتشف أي تغيير في مجلد `pubs` فوراً، ويقوم بتحديث البيانات ورفعها تلقائياً لجيت هاب.

**لتشغيله:**
1. افتح PowerShell أو Terminal في مجلد المشروع.
2. قم بتشغيل الأمر:
   ```bash
   python watch_pubs.py
   ```
3. الآن، بمجرد سحب وإفلات أي ملف PDF داخل مجلد `pubs` أو حذفه، سيقوم البوت تلقائياً بـ:
   - تحديث ملف `publications.xml` بالأسماء والتواريخ الجديدة.
   - عمل `git commit` تلقائي برسالة توضح الملفات المضافة أو المحذوفة.
   - عمل `git push` لرفع الأوراق البحثية والموقع إلى جيت هاب مباشرة لتحديث موقعك على الإنترنت فوراً!

---

### 🅱️ الطريقة الثانية: البوت السحابي (GitHub Actions Workflow)
إذا قمت برفع ملفات PDF مباشرة من خلال موقع GitHub على الإنترنت أو نسيت تشغيل البوت المحلي، فإن جيت هاب سيتولى الأمر:
1. بمجرد اكتشاف رفع ملف جديد على المستودع، يعمل سير العمل المسمى `Deploy Bio Site to GitHub Pages` تلقائياً.
2. يقوم بتشغيل `generate_xml.py` للتأكد من تحديث ملف `publications.xml`.
3. يقوم برفع وتحديث ملف `publications.xml` في المستودع.
4. ينشر الموقع المحدث مباشرة على رابط GitHub Pages الخاص بك.

## 🎨 تفعيل صفحة الموقع (Activating GitHub Pages)

في مستودعك على موقع جيت هاب:
1. اذهب إلى الإعدادات **Settings** الخاصة بالمستودع.
2. اختر **Pages** من القائمة الجانبية.
3. تحت قسم **Build and deployment**، وفي خانة **Source**، اختر **GitHub Actions** (سيتيح ذلك للبوت السحابي نشر موقعك بأمان وسرعة).
4. بعد دقائق معدودة، سيظهر لك رابط موقعك جاهزاً ومفعلاً للجميع!
